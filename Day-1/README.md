# Student Grade Processor

## Overview

A small Scala-based Student Grade Processor developed as part of Day 1 Scala Essentials.

The project processes student marks using Scala collections and calculates total marks, average marks, grades, pass/fail status, topper, and class average.

## Technologies Used

- Scala 2.13.16
- sbt
- Ubuntu/Linux
- Git & GitHub

## Scala Concepts Covered

- `val`, `var`, and `lazy val`
- Immutable collections
- `List`
- `Vector`
- `Set`
- `Map`
- `map()`
- `filter()`
- `foreach()`
- `for` comprehensions
- `yield`
- Case classes
- Traits
- Multiple trait implementations
